# Assignment 2 - Short Stack: Basic Two-tier Web Application using HTML/CSS/JS and Node.js  

## MLB Prospects Database
https://a2-justinfletcher.onrender.com/
In my project I have a webpage with a form for inputting information about baseball players, specifically younger up and coming players (prospects). You can enter biographical data and scouting data such as numbers representing different tools (hit, power, etc...). I used both flexbox and the grid CSS technique in my project. I used a flexbox between my form and my grid to align them side by side and then used a grid for my individual panels representing each player. 

## Technical Achievements
- **Single Page App**: Using a combination of GET and POST requests I was able to effectively communicate between the client and server to render player panels and add additional player panels using the form. 

### Design/Evaluation Achievements
- **Think Aloud with Noah Gaskill**:
In terms of problems with the application, Noah did not realize there was input validation for the tool value ratings. They had to be 20-80 and multiples of fives. I could explicitly state this on the website or assume domain knowledge of my userbase. I was surprised by Noah entering a date by typing instead of using the modal to select a date. His way was a more effective way to enter a date. I might change the user interface to be more clear about the input validation.   
- **Think Aloud with Josue Hernandez**:
Josue had a similar problem with my design regarding the input validation and not realizing the bounds of the input fields. Also, he suggested the design would look better with a headshot of the player since that follows more of the convention of sports websites. I was surprised when Josue said that the website would look better with player headshots because I did not consider that. Lastly, a change in the future is figuring out a way to connect to the MLB API to get a player headshot or perhaps adding the ability to upload an image to the form.
